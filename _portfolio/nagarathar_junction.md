## Introduction
This project builds a social network to find relations, visualize connections, build community directory, and network across a global diaspora.

This social network app is written in a write-once-deploy-everywhere manner. It runs seamlessly on Android, iOS, Linux, Windows, and web browsers.

Firebase handles all frontend and web hosting. Whereas, all backend functionalities are handled in Supabase, such as Authentication, Database, and Storage.

The following tools are used in this project:
+ Flutter
+ Dart
+ Firebase
+ Supabase
+ AI coding agents in VSCode

## Social Network
The social network is live and open to general public at [https://nagaratharjunction-46a17.web.app/](https://nagaratharjunction-46a17.web.app/).
